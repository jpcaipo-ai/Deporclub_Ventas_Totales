# Deporclub — Ventas Totales

Dashboard comercial autónomo de Deporclub con ventas, Ads, pipeline, calidad de datos y métricas de adquisición.

## Publicación

El sitio se sirve desde `index.html` mediante GitHub Pages. No requiere servidor, base de datos ni dependencias externas.

## Privacidad

El dashboard contiene únicamente información agregada y no publica nombres, teléfonos, correos ni identificadores personales.
